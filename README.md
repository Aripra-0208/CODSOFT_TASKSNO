# CODSOFT_TASK
INTERNSHIP TASK
 CodSoft Internship Projects

This repository contains three Python projects completed for the CodSoft internship.

 Task 1: Rule-Based Chatbot

A simple chatbot that responds to user messages using predefined rules and pattern matching.

Features:
- Responds to greetings and common questions
- Provides current date and time
- Supports ending conversations

File: `chatbot.py`

 Task 2: Tic-Tac-Toe AI

A console-based Tic-Tac-Toe game where a human player competes against an AI.

Features:
- Human plays as X
- AI plays as O
- Uses Minimax algorithm with Alpha-Beta Pruning
- AI plays optimally and cannot be beaten

File: `tic_tac_toe.py`

 Task 4: Movie Recommendation System

A content-based recommendation system that suggests movies based on user preferences.

Features:
- Displays available movies and genres
- Takes user preferences as input
- Excludes movies already watched
- Ranks recommendations based on similarity

File: `recommendation_system.py`

 Requirements

- Python 3.8 or newer
- No external Python libraries required
- Compatible with Windows, macOS, and Linux

 How to Run

Open the terminal in the project directory.

 Task 1
```bash
python chatbot.py
```

 Task 2
```bash
python tic_tac_toe.py
```

 Task 4
```bash
python recommendation_system.py
```

Use `python3` instead of `python` if required by your system.

 Conclusion

These projects demonstrate basic Python programming, rule-based chatbot development, game-playing AI, and content-based recommendation systems.
